# Comparisons

Each page takes one problem and shows how several companies solved it, side by side. Facts come only
from the [company pages](../companies/), which cite the original sources.

- [Real-time messaging](real-time-messaging.md): WhatsApp vs Discord vs Slack on holding
  connections, routing, group fan-out, storage, ordering, and offline users.
- [Feeds and fan-out](feeds-and-fan-out.md): Twitter/X vs Instagram on push vs pull fan-out, the
  celebrity problem, and ranking funnels, with Discord and Slack as the chat contrast.
- [Media delivery](media-delivery.md): Netflix vs YouTube vs Spotify vs Instagram on upload,
  encoding, CDN push vs pull, and adaptive bitrate.
- [Databases and sharding](databases-and-sharding.md): nine companies on shard keys, ID generation,
  routing layers, zero-downtime resharding, and per-data consistency.
- [Monolith to microservices](monolith-to-microservices.md): Airbnb, Twitter/X, Uber, Netflix,
  Spotify, and Instagram (which never split) on why and how to break up one big app.
- [Money and correctness](money-and-correctness.md): Stripe vs Airbnb vs Uber on idempotent retries,
  holding scarce resources, ledgers, and reconciliation.
